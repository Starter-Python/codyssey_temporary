# A1-1 | Python 콘솔 프롬프트 관리자

이 폴더는 **Python과 Git 기초 과제 A1-1**의 결과물입니다. 터미널에서 메뉴 번호를 선택하여 프롬프트를 등록하고, 목록·카테고리·검색·상세 보기·즐겨찾기 기능을 사용할 수 있습니다. 데이터는 실행 중 메모리에만 유지되므로 프로그램을 종료한 뒤 다시 시작하면 기본 예시 데이터로 초기화됩니다.

## 실행 방법

| 순서 | 명령어 또는 작업 |
| --- | --- |
| 1 | 터미널에서 이 폴더로 이동합니다. |
| 2 | `python3 prompt_manager.py`를 실행합니다. |
| 3 | 표시되는 메뉴 번호를 입력해 기능을 선택합니다. |
| 4 | 종료하려면 `8`을 입력합니다. |

프로그램은 **Python 3.10 이상**과 표준 라이브러리만 사용하므로 별도 패키지 설치가 필요하지 않습니다.

## 기능 목록

| 메뉴 | 기능 | 동작 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력받아 새 항목을 저장합니다. 빈 입력은 다시 요청하며, 제목과 내용이 모두 같은 항목은 중복 등록하지 않습니다. |
| 2 | 전체 목록 보기 | 번호, 제목, 카테고리, 즐겨찾기 상태를 표시합니다. |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 보여 줍니다. 직접 추가한 카테고리도 조회할 수 있습니다. |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 항목을 찾습니다. |
| 5 | 상세 보기 | 번호를 선택해 제목, 카테고리, 즐겨찾기 상태, 전체 내용을 봅니다. |
| 6 | 즐겨찾기 추가/해제 | 번호를 선택해 즐겨찾기 상태를 전환합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기된 항목만 모아 봅니다. |
| 8 | 종료 | 프로그램을 안전하게 종료합니다. |

## 카테고리

기본 카테고리는 **텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타**입니다. 새 프롬프트를 등록할 때 `0`을 선택하면 필요한 카테고리를 직접 입력할 수 있으며, 이후 카테고리별 조회 메뉴에도 표시됩니다.

## 기본 예시 데이터

프로그램을 처음 실행하면 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타 카테고리를 포함한 예시 프롬프트 **10개**가 등록되어 있습니다. 각 데이터는 `title`, `content`, `category`, `favorite` 키를 갖는 딕셔너리이며 전체 목록은 리스트로 관리합니다.

## 테스트

핵심 데이터 처리 로직은 표준 라이브러리 `unittest`로 확인할 수 있습니다.

```bash
python3 -m unittest discover -s tests -v
```

검증 범위에는 기본 데이터 구조, 실행별 데이터 독립성, 번호 유효성, 사용자 정의 카테고리, 검색 로직이 포함됩니다.
