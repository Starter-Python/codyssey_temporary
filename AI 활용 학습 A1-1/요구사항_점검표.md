## 4. 평가 답변 (항목 1~5 핵심)

**항목 1. 기능:** 메뉴 `1`~`14`가 동작하고, 추가는 즉시 목록에 반영되며, 검색은 `casefold()` 부분 일치, 즐겨찾기는 불리언 토글, 삭제는 `y` 확인 후 `pop`, 수정은 Enter 유지, 병합 커밋 `5aeef4c`가 있습니다.

**항목 2. 구조:** 한 함수가 한 역할만 맡습니다. 데이터는 `list[Prompt]`, 접근은 `enumerate` 순회 + 키 접근, 갱신은 키 대입입니다. 입력 검증은 `get_non_empty_input`(빈값), `is_valid_prompt_number`+`get_prompt_index`(범위), `get_menu_choice`(메뉴)에서 각각 처리합니다. 커밋은 `feat/docs/test/refactor/merge`처럼 기능 단위로 나눕니다.

**항목 3. 원리:** 순서가 있는 모음이라 `list`, 서로 다른 필드를 묶으니 `dict`를 씁니다. 종료 시점을 알 수 없어 `while True`로 반복하고, `14`·`return`으로 정상 종료, `EOF`·`Ctrl+C`는 `UserInputCancelled`로 안전 종료합니다. 검색은 `keyword in title or keyword in content`이며, 브랜치는 목록 기능을 `feature/a1-1-prompt-list`에서 완성·테스트 후 `main`에 병합했습니다.

**항목 4. 심화:** 영속화는 표준 `json`으로 구현했습니다 (`save_prompts`·`load_prompts_into`, 없거나 깨지면 안내 후 기본 유지, `ensure_ascii=False`). 같은 제목은 내용이 다르면 다른 버전으로 허용하고, 완전 중복만 차단합니다. 충돌은 `git status` 확인 → 표식 제거·내용 선택 → `add`·`commit`·테스트 순으로 해결합니다. 카테고리 변경은 `CATEGORIES`만 고치면 관련 함수가 함께 반영됩니다.

**항목 5. 보너스:** 전부 구현됨. JSON 저장·불러오기, 카테고리별 Markdown 내보내기, 수정·삭제, 상세 보기 조회수(`view_count`) 기록, 조회수 Top 정렬(`sorted(reverse=True)`).
