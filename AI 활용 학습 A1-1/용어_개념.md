## 2. Python 기초

### 변수·함수·모듈
* **변수:** 값을 담는 이름. 예: `prompts = [...]`.
* **함수:** 입력→처리→출력을 묶은 단위. 외울 말: “한 함수는 한 역할만 맡게 나눴습니다.”
* **모듈·import:** 남이 만든 기능을 불러쓰는 것. 이 과제는 `copy`·`json`·`sys`·`typing` 표준 모듈만 씁니다.
* **표준 라이브러리:** 설치 없이 쓰는 기본 기능 모음. 외울 말: “외부 패키지 없이 표준 라이브러리만으로 동작합니다.”

### 조건문·반복문
* **조건문(`if/elif/else`):** 메뉴 번호별 분기에 사용. 외울 말: “선택값에 따라 해당 함수로 분기합니다.”
* **`while True`:** 횟수를 모를 때 쓰는 무한 반복. 메뉴 전체, 빈값 재입력, 번호 재입력에 사용. 외울 말: “종료 조건이 될 때까지 계속돼야 해서 `while`을 썼고, `14`·`return`으로 나옵니다.”
* **`enumerate`:** 번호와 값을 함께 꺼내는 반복. 목록에 `1.`부터 붙일 때 사용.

### 리스트·딕셔너리
* **`list`:** 순서 있는 모음. 전체 프롬프트 보관. 외울 말: “등록 순서 보장과 메뉴 번호 매핑이 쉽습니다. 단점은 검색에 전체 순회가 필요하다는 점입니다.”
* **`dict`:** 키-값 묶음. 한 프롬프트(`title/content/category/favorite/view_count`) 보관. 외울 말: “서로 다른 필드를 이름으로 구분하고 O(1)로 접근합니다. 단점은 스키마 강제가 없어 `TypedDict`·테스트로 보완했다는 점입니다.”
* **`TypedDict`:** 딕셔너리 키 구성을 코드에 명시한 것.
* **`append`·`pop`:** 끝에 추가·꺼내어 삭제. 추가·삭제의 핵심 동작.

### 문자열·입력 처리
* **`input()`:** 키보드 한 줄 입력. 항상 문자열 반환 → 메뉴 키도 문자열(`"1"`~`"14"`).
* **`strip()`:** 앞뒤 공백 제거. 공백만 입력한 빈값 판정에 사용.
* **`isdigit()` + 범위 검사:** 번호가 숫자이며 목록 안에 있는지 확인 (`is_valid_prompt_number`).
* **`casefold()`:** 대소문자 무시 비교. 검색· clos중복 판정에 사용. 외울 말: “`lower()`보다 다국어 처리에 강합니다.”
* **`in`:** 부분 포함 검사. “제목 또는 내용 포함” 검색의 핵심.

### 복사·파일·예외
* **`deepcopy`:** 리스트 안 딕셔너리까지 통째 복사. 외울 말: “실행 간 데이터 오염을 막아 재실행하면 기본 10개로 시작합니다.”
* **JSON(`json.dump/load`):** `list[dict]`를 파일에 저장·복원하는 형식. `ensure_ascii=False`로 한글 보존. 외울 말: “내장 모듈이라 추가 설치 없이 영속화할 수 있습니다.”
* **Markdown 내보내기:** 사람이 읽는 문서용 출력. 카테고리별 `##`, 제목별 `###`로 묶음.
* **예외(`EOFError`·`KeyboardInterrupt`):** 입력 끊김·`Ctrl+C`. `read_user_input`에서 `UserInputCancelled` 하나로 통일 후 안내 종료.
* **`if __name__ == "__main__"`:** 직접 실행 때만 메뉴 시작, `import` 때는 함수만 빌려쓰게 하는 문.

### 테스트 용어
* **`unittest`:** 표준 테스트 도구. `patch`로 `input()`을 가짜 입력으로 대체, `StringIO`로 `print()`를 캡처해 검증.
* **`py_compile`:** 문법 오류만 빠르게 확인하는 검사.

| `pull` | “원격 변경을 받아옵니다.” |
