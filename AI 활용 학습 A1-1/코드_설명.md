# 코드 설명 | `prompt_manager.py`가 돌아가는 방식

위에서 아래로 읽으면 됩니다.

## 전체 흐름

```text
실행 → main()
  ├─ 터미널이 아니면 안내 후 종료
  ├─ 기본 10개를 복사해 새 목록 생성
  └─ run_menu_loop()
       ├─ 메뉴 출력
       ├─ 번호 입력·검증
       ├─ 해당 함수 실행
       └─ 14번까지 반복
```

## 데이터 설계

전체는 `list`, 한 건은 `dict`입니다 (`list[dict]`).

| 키 | 값 | 쓰임 |
| --- | --- | --- |
| `title` | 제목 문자열 | 목록·검색·상세·수정 |
| `content` | 본문 문자열 | 검색·상세·수정 |
| `category` | 분류 문자열 | 추가·수정·카테고리 조회·내보내기 |
| `favorite` | 불리언 | ⭐ 표시·토글·모아보기 |
| `view_count` | 정수 | 상세 보기 때 1 증가, Top 정렬 기준 |

| 상수 | 역할 |
| --- | --- |
| `CATEGORIES` | 기본 6개 카테고리 (바뀌지 않는 튜플) |
| `DEFAULT_PROMPTS` | 시작용 예시 10개 (`view_count: 0` 포함) |
| `MENU_OPTIONS` | `"1"`~`"14"` 메뉴 번호표 (`input()`이 문자열을 반환하므로 키도 문자열) |
| `PROMPTS_JSON_FILE` | 저장·불러오기 기본값 `prompts.json` |
| `PROMPTS_MARKDOWN_FILE` | 내보내기 기본값 `prompts_by_category.md` |

`create_initial_prompts()`는 원본을 그대로 주지 않고 `deepcopy()`로 복사합니다. 실행 중 변경이 원본에 남지 않아, 재실행하면 항상 기본 10개로 시작합니다.

## 함수 지도

| 영역 | 함수 | 역할 |
| --- | --- | --- |
| 실행 확인 | `is_interactive_terminal`, `show_terminal_execution_help` | 입력 가능한 터미널인지 확인, 아니면 안내 |
| 입력 | `read_user_input` | `input()` + `EOF`·`Ctrl+C`를 하나의 예외로 통일 |
| 입력 | `get_non_empty_input` | 빈 값이면 다시 요청 |
| 입력 | `get_menu_choice`, `get_prompt_index`, `is_valid_prompt_number` | 메뉴·번호 검증, 화면 번호(1~)를 리스트 위치(0~)로 변환 |
| 데이터 | `add_prompt` | 새 딕셔너리를 `append`, `favorite=False`, `view_count=0` |
| 데이터 | `find_duplicate_prompt`, `normalize_prompt_text` | 공백·대소문자 정리 후 중복 탐색 |
| 데이터 | `choose_category` | 기본 선택 또는 `0` 직접 입력 |
| 데이터 | `filter_prompts_by_category`, `get_view_categories` | 카테고리 필터 (원본은 그대로 둠) |
| 데이터 | `find_prompts` | 제목·내용 키워드 검색 (`casefold`로 대소문자 무시) |
| 데이터 | `toggle_favorite`, `get_favorite_prompts` | `not`으로 뒤집기, ⭐만 골라내기 |
| 데이터 | `delete_prompt` | 번호 선택 후 `y` 확인 시 `pop`으로 삭제, `n`이면 취소 |
| 데이터 | `edit_prompt` | 번호 선택 후 제목·내용·카테고리 수정 (Enter면 유지, 중복이면 취소) |
| 데이터 | `get_top_prompts`, `show_top_prompts` | 조회수 내림차순 상위 N개 |
| 저장 | `save_prompts`, `load_prompts`, `load_prompts_into` | JSON 저장·불러오기 (없거나 깨지면 안내) |
| 저장 | `normalize_loaded_prompt` | JSON 항목의 빠진 필드를 기본값으로 채움 |
| 저장 | `export_prompts_markdown` | 카테고리별 Markdown 내보내기 |
| 출력 | `show_menu` | 메뉴 1~14 출력 |
| 출력 | `format_prompt_summary`, `show_prompt_list` | 한 줄 요약(⭐·조회수 포함) + 목록/빈 목록 안내 |
| 출력 | `show_prompt_detail`, `show_favorites`, `show_prompts_by_category`, `search_prompts` | 상세(조회수 기록)·모아보기·조건별 출력 |
| 제어 | `run_menu_loop`, `main` | 메뉴 반복·분기, 시작·종료 처리 |

`if __name__ == "__main__"` 덕분에 `import`만으로는 메뉴가 실행되지 않고, 테스트에서 함수만 불러 쓸 수 있습니다.

## 핵심 흐름

**1. 추가:** `1` → 제목·내용(빈값 재입력) → 카테고리(번호 또는 `0` 직접 입력) → `append`. 직접 입력한 카테고리는 조회 목록에 자동 추가됩니다.

**2. 목록·검색·상세 차이:**

| 기능 | 고르는 기준 | 결과 |
| --- | --- | --- |
| 전체 목록 | 없음 | 전 항목 요약 |
| 카테고리 조회 | 카테고리명 | 맞는 항목 요약 |
| 검색 | 키워드 | 제목·내용 포함 항목 요약 |
| 상세 보기 | 번호 | 한 항목의 전 필드 + 조회수 1 증가 |
| Top 보기 | 조회수 | 상위 5개 요약 |

결과가 비면 `show_prompt_list()`가 `저장된 프롬프트가 없습니다.`를 출력합니다.

**3. 즐겨찾기:** 별도 목록을 두지 않고 `favorite` 값만 뒤집습니다 (`prompt["favorite"] = not prompt["favorite"]`). 모아보기는 참인 항목만 골라 보여 줍니다.

**4. 삭제·수정:** `8`은 번호 선택 → 확인(`y`) 시 `pop`, 그 외면 취소합니다. `9`는 번호 선택 → 새 값을 입력받고 Enter면 유지, 다른 항목과 완전 중복이면 취소합니다. 빈 목록이면 번호 입력 전에 안내하고 메뉴로 돌아옵니다.

**5. 중복 방지:** 제목과 내용이 모두 같을 때만 차단합니다. 앞뒤·연속 공백과 영어 대소문자는 무시합니다.

| 경우 | 결과 |
| --- | --- |
| 제목·내용 모두 같음 | 차단 + 안내 |
| 하나라도 다름 | 등록 |
| 공백·대소문자만 다름 | 같은 것으로 보고 차단 |

**6. 보너스 저장:** `11`은 `json.dump(ensure_ascii=False)`로 저장, `12`는 읽어서 현재 목록에 덮어씁니다. 파일이 없거나 깨지면 기본 데이터로 계속합니다. `13`은 카테고리별로 `## 카테고리`, `### 제목`, 내용 순서로 Markdown을 만듭니다. 저장 파일은 `.gitignore`에 있어 GitHub에 올라가지 않습니다.

## 테스트 연결

`tests/test_prompt_manager.py` 21개는 사람 대신 핵심을 확인합니다: 기본 10개·필드, 실행 간 독립성, 번호 검증, 직접 입력 카테고리, 제목·내용 검색, 중복 방지, 메뉴 `2`·`3` 출력, 삭제 확인·취소·빈 목록, 상세 조회수, Top 정렬, 수정·유지, JSON 저장·불러오기, Markdown 내보내기, 비대화형 안내, `EOF` 처리.
