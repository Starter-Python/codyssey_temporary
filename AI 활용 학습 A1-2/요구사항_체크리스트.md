# 과제 요구사항 체크리스트

이 문서는 제공된 A1-2 과제 안내문을 기준으로, Gemini API 전환 후의 구현 상태를 확인합니다. `구현 완료`는 코드와 문서 반영을 뜻하며, 실제 Gemini 호출은 사용자가 자신의 `GEMINI_API_KEY`를 `.env`에 설정한 환경에서 확인할 수 있습니다.

## 1. 최종 산출물과 CLI

| 요구사항 | 구현 위치 | 상태 |
|---|---|---|
| CLI 기반 Python 프로그램 | `travel_planner.py` | 구현 완료 |
| 필수 `-date "YYYY-MM-DD"` | `parse_args()` | 구현 완료 |
| 날짜 형식·실제 날짜 검증 | `datetime.strptime()` + `parser.error()` | 구현 완료 |
| 진행 로그·저장 경로 출력 | `main()` | 구현 완료 |
| 원본 JSON과 최종 Markdown 저장 | `write_results()` | 구현 완료 |
| 실행·보안 안내 README | `README.md` | 구현 완료 |

| 요구사항 | Gemini 전환 후 구현 | 상태 |

| OpenAI 또는 Gemini 계열 LLM | **Google Gemini API** `generateContent` REST API | 구현 완료 |

| JSON 파싱 가능한 1차 LLM 출력 | Gemini `responseMimeType`과 `responseJsonSchema` 사용 | 구현 완료 |
| 추천 JSON 필수 키 | `recommended_city`, `weather`, `events`, `reason` 검증 | 구현 완료 |

| 맛집 공통 필드 | `name`, `address`, `category`, `url`, `x`, `y` | 구현 완료 |
| 최종 Markdown 리포트 | Gemini 2차 호출 또는 `fallback_report()` | 구현 완료 |
