## 1. 지원 화면 크기 및 반응형 레이아웃 증빙

| 기기 유형 | 해상도 기준 | UI 레이아웃 변경 사항 |
|---|---|---|
| **데스크톱 (Desktop)** | $\ge 1024\text{px}$ | • 상단 고정 네비게이션 바 및 유저 셀렉터<br />• 4열 통계 카드 그리드<br />• 순위표 + 6축 레이더 차트 2열 분할 뷰<br />• AI 입력 폼 + 코칭 리포트 2열 와이드 뷰 |
| **태블릿 (Tablet)** | $768\text{px} \sim 1023\text{px}$ | • 2열 통계 카드 그리드<br />• 순위표 하단에 레이더 차트 수직 배치<br />• 참석 체크 1열 수직 배치 |
| **모바일 (Mobile)** | $< 768\text{px}$ | • 상단 메뉴 숨김 및 **하단 고정 모바일 탭바(Bottom Nav)** 활성화<br />• 1열 풀 너비 카드 레이아웃<br />• 엄지손가락 터치에 최적화된 48px 이상 터치 타깃 적용 |

## 2. AI 코칭 기능 입력 ➔ 출력 ➔ 스탯 반영 3단계 흐름 증빙

```
[ 1단계: 사용자 입력 ]
- 경기: 조재경(1부 T1) vs 문찬영(1부 T2)
- 스코어: 15 : 12
- 현장 메모: "포핸드 깊은 렝스 드라이브가 사이드월에 밀착되어 랠리 주도권을 잡았음. T-존 선제 발리로 공격 주도."
                  │
                  ▼ [ 비동기 POST /api/coach 호출 ]
[ 2단계: Gemini AI 코칭 리포트 생성 ]
- 총평: [조재경 vs 문찬영] 15:12 경기 분석...
- 잘한 점: 사이드월을 타고 흐르는 깊은 렝스 드라이브로 상대 리턴을 압박하며 T-존 선제 발리로 장악했습니다.
- 보완 조언: 팽팽한 승부처에서 체력 저하로 인한 풋워크 지연을 예방하는 페이스 조절이 필요합니다.
- 추천 드릴: 1) 사이드월 밀착 솔로 드라이브 50회, 2) T-존 연속 발리 랠리 30회
- 6대 스탯 변동: 포핸드 +1, 드라이브 +1, 발리 +1
                  │
                  ▼ [ "선수 스탯에 반영하기" 버튼 클릭 ]
[ 3단계: 선수단 6축 스탯 및 OVR 실시간 갱신 ]
- 조재경 선수 OVR: 89 ➔ 90 갱신
- 6축 레이더 차트 다각형이 실시간으로 확장되어 시각화됨
```

## 3. AI 기능 3대 실패 처리 테스트 케이스 증빙

### Test Case 1: 필수값 누락 (빈 입력)
- **입력**: 선수 미선택 또는 관찰 메모 빈칸
- **동작**: `alert-danger` 경고 배너 출력 ("경기 참가 선수를 모두 선택해 주세요") 및 네트워크 호출 차단

### Test Case 2: API 장애 / 오프라인 환경
- **조건**: 인터넷 연결 끊김 또는 API 키 미설정
- **동작**: "오프라인 룰 엔진으로 안전하게 분석을 완료했습니다" 안내와 함께 내장 휴리스틱 리포트 즉시 생성

### Test Case 3: 10초 응답 지연 (타임아웃)
- **조건**: 네트워크 지연 발생
- **동작**: `AbortController` 10초 가드레일이 작동하여 로딩 스피너를 안전하게 해제하고 안내 메시지 표시
