# 증빙 자료 수집 안내

실제 Vercel 배포를 마친 뒤 아래 4개 장면을 캡처하여 이 `evidence/` 폴더에 저장한다. 파일명에는 날짜를 넣어 관리하면 제출 시 확인하기 편하다.

| 파일명 예시 | 반드시 보여야 할 내용 | 확인 기준 |
|---|---|---|
| `01-desktop-home.png` | 데스크톱 화면의 상단 메뉴와 첫 장 | 메뉴가 보이고 ‘루틴 설계’로 이동할 수 있는지 |
| `02-mobile-routine.png` | 모바일 폭의 접힘 메뉴, 입력 폼 | 레이아웃이 깨지지 않고 버튼을 누를 수 있는지 |
| `03-ai-result.png` | 실제 입력값을 넣은 뒤 생성된 3단계 루틴 | 입력 → 로딩 → 결과 출력 흐름이 한 화면에 보이는지 |
| `04-error-empty-input.png` | 필수 선택 없이 제출했을 때의 안내 | 빈 입력 실패 처리가 보이는지 |

## 권장 캡처 방법

1. Vercel의 실제 배포 URL을 데스크톱 브라우저에서 연다.
2. `03-ai-result.png`를 만들 때는 실제 API 키가 설정된 배포 환경에서 입력 후 생성한다. API 키·환경 변수 페이지 자체는 캡처하지 않는다.
3. 모바일 증빙은 브라우저의 기기 에뮬레이션에서 폭 375px 정도로 설정하거나 실제 휴대폰에서 캡처한다.
4. 이미지 파일을 이 폴더에 넣은 뒤 README의 증빙 표에 파일명을 연결한다.

> 캡처에 API 키, Vercel 환경 변수 값, 개인 메모 등 민감한 정보가 포함되지 않았는지 업로드 전에 한 번 더 확인한다.
