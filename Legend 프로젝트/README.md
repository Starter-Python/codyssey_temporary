# Legend | 깊은 심연의 던전 크롤러

절차 생성 던전 3층을 내려가 보스 드래곤을 잡는 콘솔 로그라이크 RPG입니다.
외부 패키지 없이 표준 라이브러리만으로 동작합니다.

## 실행

```bash
cd "Legend 프로젝트"
python3 legend.py
```

`1` 새 모험 → `w/a/s/d` 이동 → `>` 계단 → 3층 보스 처치 → 전설 달성!

## 조작법

| 키 | 동작 |
| --- | --- |
| `w/a/s/d` | 이동 (몬스터에게 부딪히면 공격) |
| `e` | 물약 마시기 (체력 +15) |
| `>` | 계단에서 아래층으로 |
| `i` | 상태 보기 |
| `h` | 도움말 |
| `q` | 저장 후 종료 |

## 시스템

* **던전:** 시드 기반 절차 생성 (같은 시드=같은 지형), 방+복도, 층마다 재생성
* **시야:** 반경 8칸 + 벽 가림(LOS), 다녀간 곳은 희미하게 기억
* **몬스터:** 슬라임→고블린→오크→다크나이트→드래곤(보스), 층마다 강화. 가까우면 추적, 멀면 배회
* **성장:** 처치 XP → 레벨업(체력 전체 회복·공격+2·방어+1)
* **아이템:** 물약 `!`, 무기 `/`, 방어구 `[` (발밑 자동 획득)
* **기록:** `save.json` 이어하기, `scores.json` 명예의 전당 Top 10

## 테스트

```bash
python3 -m unittest discover -s tests -v

```

## 파일

| 파일 | 역할 |
| --- | --- |
