# Legend FPS | 터미널 + 그래픽 레이캐스팅 FPS

울펜슈타인 방식 레이캐스팅으로 진짜 3D 원근을 만드는 FPS입니다.
표준 라이브러리만 사용합니다.

## 두 가지 버전

| 버전 | 실행 | 조작 |
| --- | --- | --- |
| 터미널판 | `python3 fps.py` | `WASD`+`←/→`, Space 발사 (로컬 터미널 전용) |
| 그래픽판 (추천) | `python3 gui.py` | `WASD`+마우스 조준, 클릭 발사 |

> 그래픽판은 tkinter가 필요합니다. 맥에서 없으면 `brew install python-tk@3.12` 한 줄로 해결됩니다.

## 실행

```bash
cd "Legend 프로젝트/fps"
python3 fps.py
```

> 실시간 키 입력이 필요해서 **로컬 통합 터미널**에서만 됩니다.
> (`input()`이 아니라 키를 누르는 즉시 반응합니다.)

## 조작법

| 키 | 동작 |
| --- | --- |
| `W/S` | 전진/후진 |
| `A/D` | 옆걸음 |
| `←/→` (또는 `J/L`) | 회전 |
| `Space` | 발사 (중앙 조준선 히트스캔) |
| `Q` | 종료 |

## 시스템

* **3D 렌더링:** 열마다 DDA 광선 → 거리별 음영(`█▓▒░·`) + 벽 재질 색상. 적은 빌보드 스프라이트로 크기·가림 처리
* **적 AI:** 12칸 안에서 추적, 0.6칸에서 근접 공격
* **웨이브:** 1→5, 웨이브마다 +1마리·체력+20. 5웨이브 전멸 시 승리 (+1000점)
* **생존:** 처치 시 체력 +10 회복, 조준 중인 적의 체력·거리 표시
* **기록:** `fps_scores.json` Top 10
