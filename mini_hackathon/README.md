## 📌 문제 정의 (Problem Statement)

반도체 제조 공정에서는 수백 개의 센서가 온도, 압력, 가스 유량, 전력 등을
실시간으로 측정합니다. 미세한 공정 이상이 **웨이퍼 불량(수율 하락)**으로
이어지기 때문에, 조기에 이상을 탐지하고 불량을 예측하는 것이 핵심 과제입니다.

### 우리가 푸는 과제
1. **수율 예측 (Classification)**: 공정 센서 값으로 해당 웨이퍼 로트가
   `양품(pass)`인지 `불량(fail)`인지 예측한다.
2. **핵심 인자 도출 (Feature Importance)**: 어떤 공정 변수가 불량에
   가장 큰 영향을 주는지 찾아 현장에 인사이트를 제공한다.
3. **이상탐지 (Anomaly Detection)**: 라벨 없이도 비정상 로트를 탐지한다.

## 🔬 접근 방법 (Approach)
| 단계 | 내용 | 기법 |
|------|------|------|
| 1. 데이터 이해 | 센서 분포, 결측, 불균형 확인 | EDA |
| 2. 전처리 | 스케일링, 결측 처리, 불균형 대응 | StandardScaler |
| 3. 모델링 | 양품/불량 분류 | RandomForest, LogisticRegression |
| 4. 평가 | 불균형 데이터에 맞는 지표 | ROC-AUC, F1, PR curve |
| 5. 해석 | 불량 핵심 인자 도출 | Feature Importance |
| 6. 이상탐지 | 라벨 없는 이상 탐지 | IsolationForest |

## 🎯 해커톤 관점 포인트
- **SHOW & PROVE**: 작동하는 결과물 + 시각화로 증명
- **REAL BUSINESS**: 정확도만이 아니라 "불량을 놓치지 않는 것"(recall)이 중요
- **인사이트**: 모델 성능뿐 아니라 "왜 불량이 생기는가"를 설명
